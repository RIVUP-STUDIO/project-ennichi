# Project 縁日 Prototype Ver.4

クロード版の操作ルールを参考にし、Project 縁日の画面デザインと統合した試作です。

## Ver.4の特徴

- 針は最初から画面上に存在
- 針の持ち手をつかんで運ぶ
- 黄色い開始点へ触れるまで判定開始しない
- 点線上は緑で進行
- 外側へ外れても即アウトにはならない
- 内側へ一定以上入ると即アウト
- 指を離しても針はその場に残る
- 日の丸・ハート・星のステージ
- 縁日の紙・飴を意識した画面デザイン
