# Project 縁日 型抜きゲーム Prototype Ver.2

Ver.2では操作感を大きく変更しました。

## 主な変更

- 指ではなく「針先」で判定
- 針先を指の約1cm上に表示
- 点線に近いと軽く吸着する補正
- 点線上は緑
- 少し外れると黄色
- 危険域は赤
- 判定幅を大幅に縮小
- 通過した点線が緑に変化
- カリカリ音と微振動
- フリーハンド感を抑制
